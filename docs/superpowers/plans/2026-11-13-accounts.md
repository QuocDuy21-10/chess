# Accounts, Match History and Ratings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Online play needs an account: players sign in with Google or GitHub, every finished online game is saved in PostgreSQL with the Elo change it caused, and the menu shows the player's profile and match history while the HUD shows both players' names and ratings.

**Architecture:** The Express game server owns everything new. `db.ts` opens a `pg` pool with Drizzle and applies the SQL migrations in `apps/server/drizzle/` under an advisory lock at startup; `schema.ts` declares four tables (`users`, `accounts`, `sessions`, `games`). `auth.ts` runs the OAuth flow through `providers.ts` (Arctic) and opens a session (`sessions.ts`) kept in an httpOnly `sid` cookie; `api.ts` answers `/me` and `/me/games`. Socket.IO checks the same cookie in an `io.use` middleware, so a seat belongs to a user id the server knows rather than a `playerId` the browser sends. When a game ends, `game.ts` hands the room's record to `games.ts`, which saves it and moves both ratings (`elo.ts`) in one transaction. The site gains a `useAccount` store and sign-in, profile and history panels in the menu.

**Tech Stack:** Node 22.18+ (type stripping, no build step), Express 5.3, Socket.IO 4.8, PostgreSQL 17 (13 or later works), `drizzle-orm@0.45.4` + `drizzle-kit@0.31.11`, `pg@8.23.1`, `arctic@3.7.0`, `cookie@2.0.2`, `cors@2.8.6`, Vitest 5.1, Docker Compose for the development database. Unchanged: Next.js 16.4.6, React 19.3, zustand 5, chess.js 1.4.

**Spec:** `docs/superpowers/specs/2026-11-13-accounts-design.md`

## Global Constraints

- New server dependencies, and nothing else: `drizzle-orm@^0.45.4`, `pg@^8.23.1`, `arctic@^3.7.0`, `cookie@^2.0.2`, `cors@^2.8.6`; dev: `drizzle-kit@^0.31.11`, `@types/pg@^8.23.1`, `@types/cors@^2.8.19`. The site gains no dependency. No `passport`, `express-session`, `cookie-parser`, `supertest`, `pino` or rate limiter (rate limiting and structured logging are Phase 5).
- Node runs every file in `apps/server/src` and `packages/shared/src` without compiling it: `import type` for type-only imports, `.ts` on every relative import, no enums, namespaces, decorators or constructor parameter properties. `tsc` refuses a mistake (`erasableSyntaxOnly`, `verbatimModuleSyntax`).
- The browser is never trusted with identity: no `playerId` remains anywhere. The server reads the user from the `sid` cookie on every HTTP route that needs one and once per socket connection.
- The database stores only the SHA-256 of a session token. Accounts are keyed by the provider's stable id (`sub` for Google, the numeric `id` for GitHub), never by email; a Google and a GitHub sign-in are two users.
- Cookies: `sid` is `HttpOnly; SameSite=Lax; Path=/; Max-Age=2592000`, `Secure` only when `NODE_ENV=production` (Safari drops `Secure` cookies on `http://localhost`). No `Domain` attribute.
- `ended_at` is always written from a JS `Date` (millisecond precision); the history keyset relies on it.
- Server tests that touch the database need Postgres and `TEST_DATABASE_URL`; they truncate the four tables. `apps/server` runs its test files one at a time.
- `AGENTS.md`: this Next.js differs from older ones. Before writing Next.js-specific code that is not copied from this plan, read the matching guide in `node_modules/next/dist/docs/`.
- Run every command from the repository root (the folder that contains `docs/`) unless a step says otherwise.
- Work on the branch `accounts`, created from `main`. Commit only the paths each task names. Never commit `roadmap.md`, `roadmap-2.md`, `design-3D.md`, `3D-Stylized.md`, `chess.jpeg`, `.vitest/` or any `.env`.
- Disk: `npm install`, `next build` and the Docker image need a few GB free. If the disk fills, stop and tell the user before deleting anything. (While this plan was written the disk filled and Docker Desktop stopped; it took the user's other containers down with it.)

## Where this plan differs from the spec

Found while building it; the spec is otherwise followed as written.

- **`cookies.ts`** is a new file: `auth.ts`, `api.ts` and `game.ts` all read the `sid` cookie, so the cookie names, the reader and the options live in one place.
- **`close()` waits for games being saved** (Task 7). The spec said the save is not awaited; it still is not awaited by the game, but without this a `SIGTERM` can end the pool under a game being written, and the tests deadlock on `TRUNCATE`.
- **An invite link keeps `?room=` when the server says "signed out"** (Task 8). `quit()` cleared the address, so the sign-in link lost the room the spec promises to come back to.
- **`onError` keeps a client's 4xx** (bad JSON, a body over 1 kB) instead of answering 500 (Task 5).
- **`.dockerignore` gains `**/.env`** (Task 10): the image copied a developer's OAuth secrets.
- **The account store has an `'unreachable'` status** besides the spec's three, so the menu can say the server is down rather than offer sign-in buttons that lead nowhere.
- **"A flag with a lone-king winner saves a draw"** is tested in `games.test.ts` (saving a `timeout-insufficient` record) and `rooms.test.ts` (`timeoutResult`), not over sockets in `app.test.ts`: reaching a lone king through real moves would take dozens of them.
- **The server's `dev` script reads `apps/server/.env`** (`node --env-file-if-exists=.env`), and both Vitest configs load it, so no new dependency such as `dotenv` is needed.

```ts
// Elo, as FIDE runs it: a new player's rating moves faster until it has settled.

const PROVISIONAL_GAMES = 30;
const NEW_K = 40;
const SETTLED_K = 20;

/** The points a player wins (or, negative, loses) in one game. `score`: 1 win, 0.5 draw, 0 loss. */
export function eloDelta(rating: number, opponent: number, gamesPlayed: number, score: 0 | 0.5 | 1): number {
  const expected = 1 / (1 + 10 ** ((opponent - rating) / 400));
  const k = gamesPlayed < PROVISIONAL_GAMES ? NEW_K : SETTLED_K;
  return Math.round(k * (score - expected));
}
```

```ts
import { fileURLToPath } from 'node:url';
import { drizzle, type NodePgDatabase } from 'drizzle-orm/node-postgres';
import { migrate as runMigrations } from 'drizzle-orm/node-postgres/migrator';
import pg from 'pg';
import * as schema from './schema.ts';

const MIGRATIONS = fileURLToPath(new URL('../drizzle', import.meta.url));
const MIGRATION_LOCK = 7_421_001; // any fixed number; only this server takes this advisory lock

export type Db = NodePgDatabase<typeof schema>;

/** A connection pool and the Drizzle client over it. Nothing connects until the first query. */
export function connect(url: string) {
  const pool = new pg.Pool({ connectionString: url });
  // An idle connection the database drops (a restart, a failover) must not end the process.
  pool.on('error', (error) => console.error('Postgres connection lost:', error.message));
  return { pool, db: drizzle({ client: pool, schema }) };
}

/** Applies the migrations in drizzle/ that have not run. Two servers starting together apply them once. */
export async function migrate(pool: pg.Pool): Promise<void> {
  const client = await pool.connect();
  try {
    await client.query('SELECT pg_advisory_lock($1)', [MIGRATION_LOCK]);
    try {
      await runMigrations(drizzle({ client }), { migrationsFolder: MIGRATIONS });
    } finally {
      await client.query('SELECT pg_advisory_unlock($1)', [MIGRATION_LOCK]);
    }
  } finally {
    client.release();
  }
}
```

```ts
import { createHash, randomBytes } from 'node:crypto';
import type { User } from '@chess/shared/account';
import { and, eq, gt, lte } from 'drizzle-orm';
import type { Db } from './db.ts';
import { sessions, users } from './schema.ts';

export const SESSION_MS = 30 * 24 * 60 * 60_000; // fixed from sign-in, not sliding

/** The table keeps only this, so a copy of it opens no session. */
const hash = (token: string) => createHash('sha256').update(token).digest();

/** Signed-in sessions. The token lives in the `sid` cookie; `now` is passed in so tests can move the clock. */
export function createSessions(db: Db, now: () => number = Date.now) {
  return {
    /** Opens a session for `userId`. Returns the token for the cookie. */
    async create(userId: string): Promise<string> {
      const token = randomBytes(32).toString('base64url');
      await db.insert(sessions).values({ tokenHash: hash(token), userId, expiresAt: new Date(now() + SESSION_MS) });
      return token;
    },

    /** The user a token belongs to, or null when it is unknown or expired. */
    async find(token: string): Promise<User | null> {
      const [user] = await db
        .select({
          id: users.id,
          name: users.displayName,
          avatar: users.avatarUrl,
          rating: users.rating,
          gamesPlayed: users.gamesPlayed,
        })
        .from(sessions)
        .innerJoin(users, eq(users.id, sessions.userId))
        .where(and(eq(sessions.tokenHash, hash(token)), gt(sessions.expiresAt, new Date(now()))));
      return user ?? null;
    },

    async remove(token: string): Promise<void> {
      await db.delete(sessions).where(eq(sessions.tokenHash, hash(token)));
    },

    /** Deletes every expired session. */
    async sweep(): Promise<void> {
      await db.delete(sessions).where(lte(sessions.expiresAt, new Date(now())));
    },
  };
}

export type Sessions = ReturnType<typeof createSessions>;
```

```ts
/** What the `oauth` cookie holds between the redirect to the provider and its callback. */
interface Flow {
  provider: ProviderName;
  state: string;
  verifier: string;
  returnTo: string;
}

/**
 * A path on the site to come back to after signing in, or "/". The browser is always sent to `webUrl` + this,
 * so another site can never be reached; refusing "//" and "/\" is a second guard.
 */
export function safeReturnTo(value: unknown): string {
  if (typeof value !== 'string' || value.length > MAX_RETURN_TO) return '/';
  return value.startsWith('/') && !value.startsWith('//') && !value.startsWith('/\\') ? value : '/';
}

function readFlow(header: string | undefined): Flow | null {
  try {
    const flow = JSON.parse(readCookie(header, OAUTH) ?? '') as Partial<Flow>;
    const strings = [flow.provider, flow.state, flow.verifier, flow.returnTo].every((v) => typeof v === 'string');
    return strings ? (flow as Flow) : null;
  } catch {
    return null;
  }
}

/** The user behind a provider account, created on the first sign-in. A later sign-in keeps the chosen name. */
export async function findOrCreateUser(db: Db, provider: ProviderName, profile: Profile): Promise<string> {
  // shortcut: two first sign-ins of one account in the same instant make the second fail with a 500; signing in
  // again works. Upgrade with ON CONFLICT if it is ever reported.
  return db.transaction(async (tx) => {
    const [found] = await tx
      .select({ userId: accounts.userId })
      .from(accounts)

    Object.hasOwn(providers, name) ? { name: name as ProviderName, provider: providers[name as ProviderName]! } : null;

    res.json(PROVIDER_NAMES.filter((name) => providers[name]));

    if (!found) return next(); // the JSON 404
    const flow: Flow = {
      provider: found.name,
      state: generateState(),
      verifier: generateCodeVerifier(),
      returnTo: safeReturnTo(req.query.returnTo),
    };
    res.cookie(OAUTH, JSON.stringify(flow), flowCookie);
    res.redirect(found.provider.authorize(flow.state, flow.verifier).toString());
  });

  router.get('/auth/:provider/callback', async (req, res, next) => {
    const found = providerOf(req.params.provider);
    if (!found) return next();
    const flow = readFlow(req.headers.cookie);
    res.clearCookie(OAUTH, { ...flowCookie, maxAge: undefined });
    const { code, state } = req.query;
    if (!flow || flow.provider !== found.name || typeof code !== 'string' || state !== flow.state) {
      return res.redirect(`${webUrl}/?login=failed`); // refused on the provider's page, replayed, or expired
    }
    let profile: Profile;
    try {
      profile = await found.provider.identify(code, flow.verifier);
    } catch (error) {
      console.error(`Sign-in with ${found.name} failed:`, error);
      return res.redirect(`${webUrl}/?login=failed`);
    }
    const userId = await findOrCreateUser(db, found.name, profile);
    res.cookie(SID, await sessions.create(userId), sidCookie);
    res.redirect(`${webUrl}${safeReturnTo(flow.returnTo)}`);
  });

  router.post('/auth/logout', async (req, res) => {
    const token = readCookie(req.headers.cookie, SID);
    if (token) {
      const user = await sessions.find(token);
      await sessions.remove(token);
      if (user) onLogout?.(user.id);
    }
    res.clearCookie(SID, { ...sidCookie, maxAge: undefined });
    res.status(204).end();
  });

  return router;
}
```

```ts
export const PROVIDER_NAMES = ['google', 'github'] as const;
export type ProviderName = (typeof PROVIDER_NAMES)[number];

/** Who the provider says signed in. `id` is the provider's stable id, never an email or a login. */
export interface Profile {
  id: string;
  name: string;
  avatar: string | null;
}

export interface Provider {
  /** The provider's sign-in page. GitHub takes no PKCE verifier and ignores it. */
  authorize(state: string, verifier: string): URL;
  /** Trades the callback's code for the player's profile. Throws when the provider refuses the code. */
  identify(code: string, verifier: string): Promise<Profile>;
}

const NAME_LENGTH = 32;
const FALLBACK_NAME = 'Player';

/** A provider's name made to fit `users.display_name`: trimmed, at most 32 characters, never empty. */
export function cleanName(raw: string | null | undefined): string {
  const name = Array.from((raw ?? '').trim()) // characters, not UTF-16 units, as Postgres counts them
    .slice(0, NAME_LENGTH)
    .join('')
    .trim();
  return name || FALLBACK_NAME;
}

function google({ clientId, clientSecret }: OAuthApp, redirectUri: string): Provider {
  const client = new Google(clientId, clientSecret, redirectUri);
  return {
    authorize: (state, verifier) => client.createAuthorizationURL(state, verifier, ['openid', 'profile']),
    async identify(code, verifier) {
      const tokens = await client.validateAuthorizationCode(code, verifier);
      // The ID token came straight from Google over TLS in exchange for the code, so it is not verified again.
      const claims = decodeIdToken(tokens.idToken()) as { sub: string; name?: string; picture?: string };
      return { id: claims.sub, name: cleanName(claims.name), avatar: claims.picture ?? null };
    },
  };
}

function github({ clientId, clientSecret }: OAuthApp, redirectUri: string): Provider {
  const client = new GitHub(clientId, clientSecret, redirectUri);
  return {
    authorize: (state) => client.createAuthorizationURL(state, []), // no scopes: the public profile is enough
    async identify(code) {
      const tokens = await client.validateAuthorizationCode(code);
      const response = await fetch('https://api.github.com/user', {
        headers: {
          Authorization: `Bearer ${tokens.accessToken()}`,
          Accept: 'application/vnd.github+json',
          'User-Agent': 'combat-chess', // GitHub refuses requests without one
        },
      });
      if (!response.ok) throw new Error(`GitHub /user answered ${response.status}`);
      const user = (await response.json()) as { id: number; login: string; name: string | null; avatar_url: string };
      return { id: String(user.id), name: cleanName(user.name || user.login), avatar: user.avatar_url || null };
    },
  };
}
```

```ts
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/;

/** Puts the signed-in user in `res.locals.user`, or answers 401. */
function signedIn(sessions: Sessions): RequestHandler {
  return async (req, res, next) => {
    const token = readCookie(req.headers.cookie, SID);
    const user = token ? await sessions.find(token) : null;
    if (!user) return void res.status(401).json({ error: 'unauthorized' });
    res.locals.user = user;
    next();
  };
}

/** `before=<endedAt ISO>,<id>` from the previous page, or null for the first page. Undefined when malformed. */
function readCursor(value: unknown): { endedAt: Date; id: string } | null | undefined {
  if (value === undefined) return null;
  if (typeof value !== 'string') return undefined;
  const comma = value.lastIndexOf(',');
  const endedAt = new Date(value.slice(0, comma));
  const id = value.slice(comma + 1);
  return comma > 0 && !Number.isNaN(endedAt.getTime()) && UUID.test(id) ? { endedAt, id } : undefined;
}

interface HistoryRow {
  id: string;
  color: Color;
  opponent_name: string;
  opponent_avatar: string | null;
  minutes: number;
  winner: Color | null;
  reason: Result['reason'];
  rating_before: number;
  delta: number;
  ended_at: Date;
}

/**
 * One page of a player's games, newest first. Each half of the UNION reads its own index, already in order;
 * `ended_at` always has millisecond precision (it is written from a JS Date), so the keyset is exact.
 */
export async function history(db: Db, userId: string, before: { endedAt: Date; id: string } | null): Promise<HistoryPage> {
  const after = before ? sql`AND (ended_at, id) < (${before.endedAt.toISOString()}::timestamptz, ${before.id}::uuid)` : sql``;
  const { rows } = await db.execute<HistoryRow & Record<string, unknown>>(sql`
    SELECT g.id, g.color, u.display_name AS opponent_name, u.avatar_url AS opponent_avatar, g.minutes, g.winner,
           g.reason, g.rating_before, g.delta, g.ended_at
    FROM (
      (SELECT id, 'w' AS color, black_id AS opponent_id, minutes, winner, reason,
              white_rating AS rating_before, white_delta AS delta, ended_at
       FROM games WHERE white_id = ${userId} ${after}
       ORDER BY ended_at DESC, id DESC LIMIT ${PAGE + 1})
      UNION ALL
      (SELECT id, 'b', white_id, minutes, winner, reason, black_rating, black_delta, ended_at
       FROM games WHERE black_id = ${userId} ${after}
       ORDER BY ended_at DESC, id DESC LIMIT ${PAGE + 1})
    ) g
    JOIN users u ON u.id = g.opponent_id
    ORDER BY g.ended_at DESC, g.id DESC
    LIMIT ${PAGE + 1}`);
  const page = rows.slice(0, PAGE);
  const last = page.at(-1);
  return {
    games: page.map(
      (row): HistoryEntry => ({
        id: row.id,
        color: row.color,
        opponent: { name: row.opponent_name, avatar: row.opponent_avatar },
        minutes: row.minutes,
        result: (row.winner ? { reason: row.reason, winner: row.winner } : { reason: row.reason }) as Result,
        ratingBefore: row.rating_before,
        delta: row.delta,
        endedAt: new Date(row.ended_at).toISOString(),
      }),
    ),
    next: rows.length > PAGE && last ? `${new Date(last.ended_at).toISOString()},${last.id}` : null,
  };
}

/** /me: the signed-in player's profile and games. */
export function apiRoutes({ db, sessions }: { db: Db; sessions: Sessions }) {
  const router = Router();
  router.use('/me', signedIn(sessions));

  router.get('/me', (_req, res) => {
    res.json(res.locals.user satisfies User);
  });

  router.patch('/me', async (req, res) => {
    const raw: unknown = req.body?.name;
    const name = typeof raw === 'string' ? raw.trim() : '';
    const length = Array.from(name).length; // characters, as Postgres counts them
    if (length < 1 || length > NAME_LENGTH) return void res.status(400).json({ error: 'bad-request' });
    const user = res.locals.user as User;
    await db.update(users).set({ displayName: name }).where(eq(users.id, user.id));
    res.json({ ...user, name } satisfies User);
  });

  router.get('/me/games', async (req, res) => {
    const before = readCursor(req.query.before);
    if (before === undefined) return void res.status(400).json({ error: 'bad-request' });
    res.json(await history(db, (res.locals.user as User).id, before));
  });

  return router;
}
```

### Task 6: Players are their session, not a browser id

The identity change. `io.use` reads `sid` from the handshake and refuses a connection without a live session (`unauthorized`); the socket joins `user:<id>` so signing out can close every connection of that account. The protocol drops `playerId` from `create` and `join`, and `RoomState` gains `players` (names and ratings, never user ids). On the site, `online.ts` forgets `playerId`/`localStorage`, connects `withCredentials`, and maps `unauthorized` to the new error `'signed-out'`. In `online.test.ts`, Node has no cookie jar, so `socket.io-client` is wrapped to add this device's cookie to the store's socket.

### Task 7: Saving finished games and moving ratings

```ts
import { eq, inArray } from 'drizzle-orm';
import type { Db } from './db.ts';
import { eloDelta } from './elo.ts';
import type { GameRecord } from './rooms.ts';
import { games, users } from './schema.ts';

/** Saves a finished game and moves both players' ratings by it, all or nothing. */
export async function saveGame(db: Db, game: GameRecord): Promise<void> {
  await db.transaction(async (tx) => {
    // Locked in id order, so two games ending at once for overlapping players wait for each other instead of
    // deadlocking, and neither rating update is lost.
    const rows = await tx
      .select({ id: users.id, rating: users.rating, gamesPlayed: users.gamesPlayed })
      .from(users)
      .where(inArray(users.id, [game.white.id, game.black.id]))
      .orderBy(users.id)
      .for('update');
    const white = rows.find((row) => row.id === game.white.id);
    const black = rows.find((row) => row.id === game.black.id);
    if (!white || !black) throw new Error(`room ${game.roomId}: a player no longer exists`);

    const { result } = game;
    const winner = 'winner' in result ? result.winner : null;
    const score = winner === 'w' ? 1 : winner === 'b' ? 0 : 0.5;
    const whiteDelta = eloDelta(white.rating, black.rating, white.gamesPlayed, score);
    const blackDelta = eloDelta(black.rating, white.rating, black.gamesPlayed, winner === 'b' ? 1 : winner === 'w' ? 0 : 0.5);

    await tx.insert(games).values({
      whiteId: white.id,
      blackId: black.id,
      minutes: game.minutes,
      winner,
      reason: result.reason,
      moves: game.moves,
      whiteRating: white.rating,
      blackRating: black.rating,
      whiteDelta,
      blackDelta,
      startedAt: new Date(game.startedAt),
      endedAt: new Date(game.endedAt), // millisecond precision: history's keyset relies on it
    });
    for (const [row, delta] of [[white, whiteDelta], [black, blackDelta]] as const) {
      await tx
        .update(users)
        .set({ rating: row.rating + delta, gamesPlayed: row.gamesPlayed + 1 })
        .where(eq(users.id, row.id));
    }
  });
}
```

```ts
/** A call to the game server with the sid cookie. */
const call = (path: string, init: RequestInit = {}) =>
  fetch(serverUrl() + path, {
    ...init,
    credentials: 'include',
    headers: init.body ? { 'content-type': 'application/json' } : undefined,
  });

/** Takes ?login=failed out of the address, keeping the rest (an invite link's ?room=). Returns whether it was there. */
function takeLoginFailed(): boolean {
  const params = new URLSearchParams(location.search);
  if (params.get('login') !== 'failed') return false;
  params.delete('login');
  const query = params.toString();
  history.replaceState(null, '', query ? `${location.pathname}?${query}` : location.pathname);
  return true;
}

export const useAccount = create<AccountState>((set) => ({
  status: 'loading',
  user: null,
  providers: [],
  loginFailed: false,

  async load() {
    if (takeLoginFailed()) set({ loginFailed: true });
    try {
      const [me, providers] = await Promise.all([call('/me'), call('/auth/providers')]);
      if (!providers.ok) throw new Error(`providers: ${providers.status}`);
      set({ providers: (await providers.json()) as string[] });
      if (me.status === 401) return set({ status: 'signed-out', user: null });
      if (!me.ok) throw new Error(`me: ${me.status}`);
      set({ status: 'signed-in', user: (await me.json()) as User, loginFailed: false });
    } catch {
      set({ status: 'unreachable', user: null });
    }
  },

  async rename(name) {
    const res = await call('/me', { method: 'PATCH', body: JSON.stringify({ name }) });
    if (res.status === 401) set({ status: 'signed-out', user: null });
    if (!res.ok) return false;
    set({ user: (await res.json()) as User });
    return true;
  },

  async logout() {
    await call('/auth/logout', { method: 'POST' }).catch(() => {}); // signed out here either way
```

```tsx
                  {resultText(t, game.result)} · {t.minutes(game.minutes)} · {date.format(new Date(game.endedAt))}
                </span>
              </span>
              <span className="font-mono">{signed(game.delta)}</span>
            </li>
          ))}
        </ul>
        {loading && (

            {t.loadingHistory}
          </p>
        )}
        {next && !loading && (
          <button onClick={loadMore} className={secondary}>
            {t.loadMore}
          </button>
        )}
      </section>

      <button onClick={onBack} className={secondary}>
        {t.back}
      </button>
    </>
  );
}
```
