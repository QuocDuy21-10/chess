# Assets: Caching, Music, Engine Loading and the Bundle Budget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cache the engine and sounds properly, halve the music's weight and download it only when audible, prefetch the engine only when a computer game is likely, take three.js out of the page's first load, and keep the JavaScript within a budget checked in CI.

**Architecture:** Cache headers in `next.config.ts`, guarded by a test that pins the engine files' hashes. `audio.ts` creates the music element in a new `startMusic()` that refuses while muted or silent. `engine/prefetch.ts` warms the HTTP cache when the computer panel opens. `squareToWorld` returns a plain `Point`, so the store→sequencer chain no longer imports three.js; an ESLint rule keeps three out of non-scene code. `scripts/bundle-size.ts` reads Next's `route-bundle-stats.json` and compares gzip sizes with `bundle-budget.json`.

**Tech Stack:** Next.js 16.4 (Turbopack), three.js 0.187, Vitest 5, Playwright 1.64.1, ffmpeg (libmp3lame), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-13-assets-design.md`

## Global Constraints

- Branch `phase5-s1-ci-cd` (S1–S3 are on it). End every commit message with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `Cache-Control` values, exactly: `/engine/:file*` → `public, max-age=31536000, immutable`; `/audio/:file*` → `public, max-age=604800, stale-while-revalidate=86400`. They apply in every environment; S2's security headers stay production-only.
- Music: MP3, constant 128 kbps, stereo, 44.1 kHz, same file name `public/audio/music.mp3`.
- No value import of `three`, `@react-three/fiber` or `@react-three/drei` in `apps/web/src` outside the scene's components (`src/scene/**/*.tsx`); `import type` is allowed everywhere. No deep imports such as `three/src/...`.
- Budgets: the measured gzip size after Task 4, plus 5 %, rounded up to a multiple of 10 KB.
- Never read any `.env` file. Installing ffmpeg or downloading anything else is asked of the owner first.
- The site's imports use the `@/` alias without extensions; scripts run by Node import with `.ts`. Comments: one line, only the why.

import { createHash } from 'node:crypto';
import { existsSync, readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { expect, test } from 'vitest';
import { ENGINE_SCRIPT, ENGINE_WASM } from './uci';

// next.config.ts caches /engine/* as immutable for a year: a file there must never change under the same name.
const PUBLIC = fileURLToPath(new URL('../../public', import.meta.url));
const SHA256: Record<string, string> = {
  '/engine/stockfish-19-lite-single.js': 'ccb130d7ff29408531c47d859a49f91d59d4f482d05a53eb1a3231a4f624c91a',
  '/engine/stockfish-19-lite-single.wasm': 'ee4f115bdb2d32cadf96cada104a05b5ec257d7ad6f57582190b49bc71f096de',
};

test('the worker and its WASM are files under /engine/, where the immutable header applies', () => {
  expect(ENGINE_WASM).toBe(ENGINE_SCRIPT.replace(/\.js$/, '.wasm')); // the worker loads the .wasm beside itself
  for (const url of [ENGINE_SCRIPT, ENGINE_WASM]) {
    expect(url).toMatch(/^\/engine\//);
    expect(existsSync(PUBLIC + url), url).toBe(true);
  }
});

test('the engine files are byte for byte the ones browsers cache as immutable', () => {
  expect(Object.keys(SHA256).sort()).toEqual([ENGINE_SCRIPT, ENGINE_WASM].sort());
  for (const [url, hash] of Object.entries(SHA256)) {
    const actual = createHash('sha256').update(readFileSync(PUBLIC + url)).digest('hex');
    expect(actual, `${url} changed: give the new file a new name, then update uci.ts and this test`).toBe(hash);
  }
});
```

import { ENGINE_SCRIPT, ENGINE_WASM } from './uci';

let done = false;

/**
 * Warms the HTTP cache with the engine (1.8 MB) when a game against the computer becomes likely, so Start finds
 * it there. Two-player and online games never call this. A failure is ignored: the worker fetches it at Start.
 */
export function prefetchEngine(): void {
  if (done) return;
  done = true;
  for (const url of [ENGINE_SCRIPT, ENGINE_WASM]) void fetch(url, { priority: 'low' }).catch(() => {});
}
```

import type { Point } from './types';

// The little vector arithmetic the sequencer needs, on plain points: three.js loads only with the scene.

export const distance = (a: Point, b: Point) => Math.hypot(a.x - b.x, a.y - b.y, a.z - b.z);

/** The point `gap` away from `target`, on the line toward `from`. */
export function shortOf(target: Point, from: Point, gap: number): Point {
  const length = distance(target, from);
  if (length === 0) return { ...target };
  const k = gap / length;

Create `apps/web/scripts/bundle-size.ts`:
```ts
import { readdirSync, readFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { gzipSync } from 'node:zlib';

// After `next build`: the gzip size of the JavaScript `/` loads first, and of all client JavaScript, against
// bundle-budget.json. Raising a budget means editing that file, in the pull request where review sees it.

export interface Sizes {
  firstLoadKb: number;
  totalKb: number;
}

const gzipKb = (files: string[]) =>
  Math.round(files.reduce((sum, file) => sum + gzipSync(readFileSync(file)).length, 0) / 1024);

/** Measures the build in `appDir` (apps/web). */
export function measure(appDir: string): Sizes {
  const statsFile = join(appDir, '.next/diagnostics/route-bundle-stats.json');
  let stats: { route: string; firstLoadChunkPaths: string[] }[];
  try {
    stats = JSON.parse(readFileSync(statsFile, 'utf8'));
  } catch {
    throw new Error(`Cannot read ${statsFile}: run \`npm run build -w @chess/web\` first`);
  }
  const home = stats.find((entry) => entry.route === '/');
  if (!home?.firstLoadChunkPaths.length) throw new Error('The build lists no first-load chunks for /');
  const chunks = join(appDir, '.next/static/chunks');
  const all = readdirSync(chunks, { recursive: true, encoding: 'utf8' })
    .filter((file) => file.endsWith('.js'))
    .map((file) => join(chunks, file));
  return { firstLoadKb: gzipKb(home.firstLoadChunkPaths.map((path) => join(appDir, path))), totalKb: gzipKb(all) };
}

/** One line for each size over its budget; empty when everything fits. */
export function overBudget(sizes: Sizes, budget: Sizes): string[] {
  return (Object.keys(budget) as (keyof Sizes)[])
    .filter((key) => sizes[key] > budget[key])
    .map((key) => `${key}: ${sizes[key]} KB is over the budget of ${budget[key]} KB`);
}

if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const appDir = fileURLToPath(new URL('..', import.meta.url));
  const budget: Sizes = JSON.parse(readFileSync(join(appDir, 'bundle-budget.json'), 'utf8'));
  const sizes = measure(appDir);
  console.table({
    'first load of /': { gzipKb: sizes.firstLoadKb, budgetKb: budget.firstLoadKb },
    'all JavaScript': { gzipKb: sizes.totalKb, budgetKb: budget.totalKb },
  });
  const over = overBudget(sizes, budget);
  for (const line of over) console.error(line);
  process.exit(over.length ? 1 : 0);
}
```
